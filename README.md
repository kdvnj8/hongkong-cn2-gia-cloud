## 带宽、流量和实际使用怎么算

Zorocloud 香港 CN2 GIA 系列的带宽标注方式是"上行 / 下行"，比如 HK-CN2GIA-Plus 是 5Mbps 上行 / 10Mbps 下行。这里的"M"指的是 Mbps（兆比特每秒），不是 MB/s（兆字节每秒）。1 Mbps = 0.125 MB/s，所以 10Mbps 下行带宽理论峰值是 1.25 MB/s。

实际使用中，带宽决定瞬时速度，月流量决定总量。比如 HK-CN2GIA-Plus 提供 200GB 月流量，如果你的网站每天传输 6GB 数据（页面、图片、API 响应的总和），刚好用完 200GB。Zorocloud 未公开流量超限后的具体处理方式（限速、停机或额外计费），建议在控制面板监控流量使用情况，接近上限时联系客服确认续费或升级选项。

带宽和流量的关系：带宽像水管口径，流量像水费总额。10Mbps 带宽可以让你在高峰时段保持稳定输出，但如果月流量只有 200GB，跑满带宽几个小时就用完了。Zorocloud 的套餐设计是带宽和流量相对平衡的，比如 HK-CN2GIA-Max 提供 10Mbps 上行 / 15Mbps 下行和 1TB 月流量，实际网站流量不会 24 小时跑满带宽，所以够用。

如果你的业务有突发流量需求（比如促销活动、新品发布），可以提前升级到更高套餐，或者在活动结束后降回原套餐。不过降级通常需要联系客服，不像升级那么方便。

## 数据保护：RAID10 是什么

Zorocloud 香港 CN2 GIA 系列标配 RAID10 数据保护。RAID10 是 RAID1 和 RAID0 的组合：先做镜像（RAID1），再做条带化（RAID0）。简单说就是把数据写到至少两块硬盘上，同时保证读写速度。

对云主机用户来说，RAID10 的好处是：如果底层某块硬盘坏了，数据还在另一块盘上，不会丢失。这比单盘存储或 RAID0（只追求速度、不做冗余）安全得多。不过 RAID10 不能替代备份，它只能防硬件故障，不能防误删除、误操作或被黑客攻击。重要数据还是要定期备份到本地或对象存储。
